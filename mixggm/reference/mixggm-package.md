# Mixtures of Gaussian graphical models

Mixtures of Gaussian graphical models for model-based clustering with
sparse covariance and concentration matrices.

## Details

A package implementing mixtures of Gaussian graphical models for
model-based clustering with sparse covariance and concentration
matrices. Model fitting is carried out by means of a structural-EM
algorithm for parameter estimation and graph structure search.

The main functions are [`mixGGM`](mixGGM.md),
[`searchGGM`](searchGGM.md) and [`fitGGM`](fitGGM.md).
