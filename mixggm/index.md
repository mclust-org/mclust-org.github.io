# mixggm

[![CRAN_Status_Badge](http://www.r-pkg.org/badges/version/mixggm)](https://cran.r-project.org/package=mixggm)
[![CRAN_MonthlyDownloads](http://cranlogs.r-pkg.org/badges/mixggm)](https://cran.r-project.org/package=mixggm)

An [R](https://www.r-project.org/) package implementing *Mixtures of
Gaussian Graphical Models* for model-based clustering with sparse
covariance and concentration matrices.

## Installation

You can install the released version of **mixggm** from CRAN:

    install.packages("mixggm")

## Usage

See
[`help(mixGGM)`](https://mclust-org.github.io/mixggm/reference/mixGGM.md).

## References

Fop, M., Murphy, T.B., and Scrucca, L. (2019). “Model-based clustering
with sparse covariance matrices.” *Statistics and Computing*, *29*(4),
791–819. <https://doi.org/10.1007/s11222-018-9838-y>.
