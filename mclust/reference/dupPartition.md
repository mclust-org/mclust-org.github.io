# Partition the data by grouping together duplicated data

Duplicated data are grouped together to form a basic partition that can
be used to start hierarchical agglomeration.

## Usage

``` r
dupPartition(data)
```

## Arguments

- data:

  A numeric vector, matrix, or data frame of observations. If a matrix
  or data frame, rows correspond to observations (\\(n\\)) and columns
  correspond to variables (\\(d\\)).

## Value

A vector of indices indicating the partition.

## See also

[`hc`](https://mclust-org.github.io/mclust/reference/hc.md)
