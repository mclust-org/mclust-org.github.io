# Swiss banknotes data

The data set contains six measurements made on 100 genuine and 100
counterfeit old-Swiss 1000-franc bank notes.

## Usage

``` r
data(banknote)
```

## Format

A data frame with the following variables:

- Status:

  the status of the banknote: `genuine` or `counterfeit`

- Length:

  Length of bill (mm)

- Left:

  Width of left edge (mm)

- Right:

  Width of right edge (mm)

- Bottom:

  Bottom margin width (mm)

- Top:

  Top margin width (mm)

- Diagonal:

  Length of diagonal (mm)

## Source

Flury, B. and Riedwyl, H. (1988). *Multivariate Statistics: A practical
approach.* London: Chapman & Hall, Tables 1.1 and 1.2, pp. 5-8.
